Füge hier deine ECHTEN Screenshots aus Cisco Packet Tracer ein:
1. topology.png oder screenshot_topology.png – vollständige Topologie
2. vlan_brief.png – `show vlan brief`
3. trunk.png – `show interfaces trunk`
4. dhcp_bindings.png – `show ip dhcp binding`
5. acl_test.png – erfolgreicher Test, dass Gäste interne Netze nicht erreichen

Die bereitgestellte Grafik unter docs/topology.png ist ein Topologieplan, kein Screenshot aus Packet Tracer.
